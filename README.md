# قیمت‌گر

اپ مدیریت مواد اولیه، کالا و لیست قیمت. یک اپ وب ساده (HTML/CSS/JS خالص، بدون نیاز به فریم‌ورک) که به دو روش می‌توانید آن را روی موبایل نصب کنید.

## روش ۱ — نصب سریع به‌صورت PWA (بدون نیاز به بیلد، چند دقیقه‌ای)

۱. یک ریپازیتوری جدید در گیت‌هاب بسازید و تمام فایل‌های این پوشه را در آن آپلود کنید (یا با گیت پوش کنید).
۲. به تنظیمات ریپو بروید: **Settings → Pages** و source را روی شاخه `main` قرار دهید.
۳. بعد از چند دقیقه یک لینک به شکل `https://username.github.io/repo-name/` فعال می‌شود.
۴. آن لینک را روی گوشی، در کروم یا سافاری باز کنید و از منو گزینه‌ی **«Add to Home Screen» / «افزودن به صفحه اصلی»** را بزنید.

اپ مثل یک اپ نصبی روی صفحه اصلی گوشی می‌نشیند، آفلاین هم کار می‌کند (به لطف `sw.js`) و اطلاعات روی خود گوشی ذخیره می‌ماند.

## روش ۲ — ساخت فایل نصبی APK واقعی (خودکار با گیت‌هاب اکشن)

این پروژه از قبل با **Capacitor** و یک ورک‌فلوی گیت‌هاب اکشن (`.github/workflows/build-apk.yml`) آماده شده که به‌صورت خودکار یک فایل APK می‌سازد:

۱. همین پوشه را در یک ریپازیتوری گیت‌هاب push کنید.
۲. به تب **Actions** در گیت‌هاب بروید — به‌محض push، ورک‌فلوی «Build Android APK» خودش اجرا می‌شود (اولین بار ممکن است چند دقیقه طول بکشد).
۳. بعد از اتمام، در همان صفحه‌ی اجرا، پایین صفحه بخش **Artifacts** را باز کنید و فایل `price-app-debug-apk` را دانلود کنید — یک فایل zip حاوی `app-debug.apk` است.
۴. آن APK را روی گوشی اندروید منتقل کرده و نصب کنید (لازم است گزینه‌ی «نصب از منابع ناشناس» را در گوشی فعال کنید).

> این APK نسخه‌ی «debug» است و برای تست و استفاده‌ی شخصی کاملاً کار می‌کند. اگر بعداً خواستید آن را در گوگل‌پلی منتشر کنید، باید نسخه‌ی release و امضاشده بسازید — در آن مرحله هم می‌توان کمک گرفت.

### ساخت محلی (اختیاری، اگر خواستید روی سیستم خودتان هم بسازید)

```bash
npm install
npx cap add android
npx cap sync android
cd android
./gradlew assembleDebug
```

فایل خروجی در مسیر `android/app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## ساختار پروژه

```
index.html          اپ اصلی
manifest.json        تنظیمات PWA
sw.js                 سرویس‌ورکر برای کارکرد آفلاین
icons/                آیکون‌های اپ
capacitor.config.json تنظیمات بسته‌بندی موبایل
package.json          وابستگی‌های Capacitor
.github/workflows/    ساخت خودکار APK با گیت‌هاب اکشن
```

## نکته درباره‌ی اطلاعات

اطلاعات (مواد اولیه، کالاها، قیمت‌ها) روی حافظه‌ی محلی خود دستگاه ذخیره می‌شود. برای پشتیبان‌گیری یا انتقال بین دستگاه‌ها، از تب «تنظیمات» داخل اپ گزینه‌ی «دانلود فایل پشتیبان» را بزنید.
